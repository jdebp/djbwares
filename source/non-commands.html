non-command list

The djbwares toolset comprises these things that are not commands. See their manual pages for documentation.

Libraries

  • caldate — calendar dates

  • caldate_easter — determine the date of Easter for any given year

  • caldate_fmt — format a calendar date into ISO 8601 human readable form

  • caldate_frommjd — create a calendar date from a MJD

  • caldate_mjd — calculate the MJD of a given calendar date

  • caldate_normalize — renormalize a calendar date

  • caldate_scan — scan a calendar date from ISO 8601 human readable form

  • caltime — calendar dates and times

  • caltime_fmt — format a calendar date+time into ISO 8601 human-readable form

  • caltime_scan — scan a calendar date+time from ISO 8601 human-readable form

  • caltime_tai — convert a calendar date+time to TAI64

  • caltime_utc — convert a calendar date+time from TAI64 with a zero UTC offset

  • leapsecs_read — (re-)initialize the leap seconds table from the data file

  • leapsecs_init — initialize the leap seconds table from the data file, at most once

  • leapsecs_add — convert a UTC seconds count plus leap seconds count to a TAI seconds count

  • leapsecs_sub — convert a TAI seconds count to a UTC seconds count plus leap seconds count

  • sgetopt — get option character from command line

  • subgetopt — get option character from command line

  • tai — manipulate times with 1-second precision

  • tai_add — add two TAI64 timestamps

  • tai_less — compare two TAI64 timestamps

  • tai_now — get current time, with 1-second precision

  • tai_pack — convert TAI64 labels to external format

  • tai_sub — subtract two TAI64 timestamps

  • tai_unpack — convert TAI64 labels from external format

  • taia — manipulate times with 1-attosecond precision

  • taia_add — add two TAI64NA timestamps

  • taia_approx — approximate a TAI64NA timestamp to 1 second

  • taia_frac — approximate the attoseconds part of a TAI64NA timestamp

  • taia_half — divide a TAI64NA timestamp by 2

  • taia_less — compare two TAI64NA timestamps

  • taia_now — get current time, with 1-attosecond precision

  • taia_pack — convert TAI64NA labels to external format

  • taia_sub — subtract two TAI64NA timestamps

  • taia_tai — convert a TAI64NA label to the encompassing TAI64 label

  • taia_unpack — convert TAI64NA labels from external format

Miscellany

  • tcp-environ — UCSPI-TCP environment variables
